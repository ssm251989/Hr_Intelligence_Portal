33.1 NUMBERS FROM REAL DATA
  a. Script backend/scripts/ai_cost_report.py (read-only): for a date range, per company (all companies on this
     install), from the recorded AI usage rows:
     - cost per resume screened, per JD drafted, per job (all AI on that job), per hire (application to joined),
       per employee exit, per HR-assistant question, per agent (screening, job, scheduling, salary, bgv reader,
       interview summary, briefing ...);
     - tokens in/out and calls behind each number; min / median / 90th percentile, not only the average;
     - in INR and USD (setting ai.fx_rates), model by model.
  b. Say how many real samples each number rests on. Under 20 samples -> mark "estimate" and also compute it from
     a controlled run (33.2).
  c. Exclude test / proof / sandbox data (sandbox company, proof jobs) and say so in the report.

33.2 CONTROLLED RUN (only where real samples are thin)
  With Mailpit on and the real model: screen 30 sample resumes (docs/samples, anonymised) against 3 JDs, draft 3
  JDs, 5 HR-assistant questions, 2 interview summaries, 2 BGV report readings. Record cost per item. Delete the
  test rows afterwards except the AI usage rows (real spend) - tag them "gate-a-run".

33.3 THE REPORT (docs/GATE_A_COST_REPORT.md + the same as an Excel file in docs/reports/)
  1. One-line answer: "AI costs about Rs X per resume, Rs Y per job, Rs Z per hire."
  2. Table per unit (resume, JD, job, hire, exit, assistant question, agent run): median, p90, samples, model.
  3. What drives cost (which agent / prompt is most expensive) and 3 concrete ways to cut it (cheaper model for
     a step, shorter prompt, caching) with the saving in Rs.
  4. Cost on Amazon Bedrock vs Anthropic direct for the same models (list prices; mark them "list price, check").
  5. Draft pricing (owner decides): three plans from the blueprint - Lite (per API call), Pro (per active job /
     month, includes the web app), Enterprise (platform fee + per hire, on-prem) - each with the AI cost inside
     it and the margin at 3 price points. Mark clearly "DRAFT - for management".
  6. Assumptions and what was excluded.
