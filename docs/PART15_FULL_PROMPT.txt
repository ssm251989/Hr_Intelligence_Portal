STEP 15.1 - DESIGN SYSTEM
- Default theme "Fresh": brand #0E7C66, coral #F26B4B, sun #F2B233,
  sky #2F6FDE, ground #F4F6F5, surface #FFFFFF, ink #15211D, muted
  #5B6A65, line #E2E8E5, plus the dark-mode values from the mockup.
  Loaded from brand_themes (tenant can override); charts derive from it.
- Font Plus Jakarta Sans via @fontsource/plus-jakarta-sans (fallback
  system-ui); tabular numbers for figures.
- Card radius 18, button radius 11, pill chips, soft two-layer shadow,
  8px spacing grid, generous white space.
- MUI theme overrides for Button, Card, Paper, Chip, Table, Tabs, Dialog,
  Drawer, TextField, Select, Tooltip, AppBar, Snackbar, Stepper so the
  MUI default look disappears everywhere.
- New app shell like the mockup: rounded sidebar with emoji + label per
  menu item grouped (Today / Hiring / People / Insights / Admin), top
  bar with Ctrl/Cmd+K search, notifications bell (grouped by module),
  profile menu, light/dark toggle. Menu built from /api/me/bootstrap.

STEP 15.2 - FRIENDLY VISUAL KIT (frontend/src/ui-kit/)
- Emoji: Microsoft Fluent Emoji (MIT) as local SVG assets so they look
  the same on every device. Component <Emoji name="..."/>.
  Menu: Home house, Approvals check, Jobs briefcase, Candidates
  technologist, Interviews calendar, Offers envelope, Onboarding waving
  hand, Employees people, Performance target, Helpdesk ring buoy,
  Assets laptop, Exits door, Reports bar chart, Settings gear.
- Status chips = colour + emoji + word, never colour alone:
  Done (check), Due soon (alarm clock), Overdue (fire), New, On hold.
- Illustrations: unDraw SVGs (free licence) recoloured to the brand
  colour; used for greetings, empty states, errors, login, wizard steps,
  pre-joiner welcome. Store in frontend/src/assets/ill/.
- Animations: lottie-react with free LottieFiles animations stored
  locally (success tick, confetti, waving hand, loader, empty box,
  rocket). canvas-confetti when an offer is signed or someone is marked
  joined (once per user per event).
- GIF/video: tenant-uploaded welcome video/GIF in the pre-joiner portal;
  "Show me how" button on each page playing a 20-40s loop (MP4/WebM,
  GIF fallback); react-joyride first-visit tour per page (skip +
  don't show again). Admin can upload/replace these in Settings.
- Avatars: photo if present, else coloured initials tile.
- Shared components: PageHeader (emoji + title + one-line purpose + ONE
  primary button), StatTile (emoji, big number WITH a word, trend),
  EmptyState (illustration + one sentence + fixing button), FriendlyError,
  StepForm (steps + progress bar + autosave), ProgressRing, Timeline,
  StageStepper, StatusChip, InfoTip.
- Motion subtle; all motion off under prefers-reduced-motion and the
  user's "reduce motion" setting.

STEP 15.3 - PLAIN LANGUAGE PASS
- Home greeting: "Good morning/afternoon/evening, <first name>" + waving
  hand + "N things need you today".
- Never show internal words (tenant, connection purpose, workflow node,
  JSONLogic, SLA policy id, scope...). Use company, mailbox, approval
  steps, rules, response time.
- Numbers always with words ("12 open jobs").
- Every error: what happened + how to fix + button to the right page.
- InfoTip on every field a new user may not understand.
- All new text through i18n with English, Hindi and Tamil.
