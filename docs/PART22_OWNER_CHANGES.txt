22.2 CANDIDATE EMAILS: "NOT MATCHED" TAB -> "CLOSED"; SMARTER AUTO-LINK
- Tabs become: Needs action | Linked to a candidate | Closed.
  Closed = emails HR has finished with (Mark done) or old/no-action emails.
  Unmatched emails are no longer a separate tab: they appear in Needs
  action with a yellow "Not linked yet" chip and a [Link to candidate]
  picker (search by name/email) that shows suggested matches.
- Auto-link rules, in order (record which rule matched on the email):
  1. sender email = candidate email (or any alternate email on the profile)
  2. sender name or signature / subject / reply thread contains the
     candidate's "First Last" OR "Last First" (case-insensitive, ignores
     extra spaces, dots, initials e.g. "G. Kishore", "Kishore G")
  3. reply to an email the app sent (thread / Message-ID)
  If exactly one candidate matches -> link automatically. If several ->
  stay in Needs action with the suggestions listed. Never guess between two.
- When HR links manually, offer "Also remember this email address for
  this candidate" (adds alternate email).
- Linked emails also appear on the candidate timeline (existing).
- Run the new matching once over existing unmatched emails.
