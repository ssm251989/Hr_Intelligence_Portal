29.3 END-TO-END WITH THE REAL MODEL (Mailpit; screenshots in docs/ui/PART29.md, one per step)
     a. New job -> careers apply with a sample resume -> within ~2 minutes the Screening agent screens it.
        Score above the threshold: "Shortlist <name>" waits on HR agents > Waiting for you (and My approvals).
        Score below: no card, the candidate stays in Screened.
     b. Approve -> interview times go out (Mailpit) -> HR agents > Journey shows: screened, shortlist
        prepared, interview times sent.
     c. A job set to "schedule interviews by hand": shortlist -> "Send interview times" card -> approve -> sent.
     d. Interviewer: scorecard "Move forward" (a person decides interviews - never an agent) -> salary form.
        Above the band -> Salary agent card (counter at the band maximum) -> approve.
     e. Candidate uploads documents -> Documents agent card -> approve -> BGV starts -> BGV agent card
        "Send BGV to <vendor>" -> approve -> vendor link -> upload a report -> the AI reading + "BGV result" card
        -> approve passed -> Offer agent "Offer joining dates" card -> approve -> candidate picks a date ->
        offer sent -> signed -> welcome portal (all on the Journey).
     f. Joining day: "Confirm <email> joined" card -> approve -> employee created.
     g. Employee resigns (employee login) -> manager approves (if the company uses the manager step) ->
        within the hour (or Exit agent "Run now") "Approve <name>'s resignation - last working day ..." ->
        Change and approve with another date -> exit checklist starts.
     h. After the last working day + clearance: "Issue relieving and experience letters" card -> approve.
     i. HR agents > Ask the agents: "who is waiting for a salary decision?" -> the agent team answers.
     j. Decline any card -> nothing changes; the screen still allows the step by hand.
     k. Switch the master off -> no new cards; switch on -> they come back (events are not replayed).
     Fix what fails (quote the error first), add a test for each fix, rerun 29.1.
